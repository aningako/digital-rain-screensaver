Digital Rain screensaver  (version 1.0.0)
=========================================
Green falling-character "code rain" for Windows 10 and 11.
Created by aning with the help of Claude.
https://github.com/aningako/digital-rain-screensaver

INSTALL
  1. Extract this whole zip to a folder (don't run it from inside the zip).
  2. Double-click Install.bat.
     It copies the screensaver to your user folder, sets it as your screensaver
     and opens Screen Saver Settings, where you can preview it and set the delay.
  No admin rights needed.

  Manual alternative: copy DigitalRain.scr to a permanent folder,
  right-click it and choose "Install".

UNINSTALL
  Double-click Uninstall.bat.

IF WINDOWS WARNS YOU
  "Windows protected your PC": the file isn't signed by a known publisher.
  Click "More info" -> "Run anyway". Or right-click the file -> Properties ->
  tick "Unblock" -> OK.
  The full source code is included (DigitalRain.cs) and on GitHub.

USING IT
  Move the mouse, click or press a key to exit the screensaver.
  Change the delay or switch it off in: Settings -> Personalization ->
  Lock screen -> Screen saver.
